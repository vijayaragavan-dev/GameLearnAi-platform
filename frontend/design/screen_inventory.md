## 13. Cross-Cutting Notes

- **Deep links:** Every `/games/:topicId/*` route is bookmarkable — `topicId` is subject-unambiguous because `Topic.subjectId` is authoritative (`Topic.fromJson`). `subjectId` query pass-through `Routes._withSubjectQuery` is additive, never required for correctness but required for `General vs Subject` visual distinction.
- **Transitions:** All full-screen routes use `router.dart:118` `_page` (`Fade+Slide/Scale`, `AppMotion.normal 300` default, `feature 500` for results, `fast 180` reverse).
- **Empty truth:** Subjects `isEmpty` → `EmptyState SHOW ALL`; dashboard no recommendations → `AssessmentNudge` + `RecentlyLearned` fallback; achievements `isEmpty` → honest empty — VIS phases must preserve these.
